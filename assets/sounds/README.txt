Puja Sound mixer audio folder
=============================

The redesigned Puja Sound mixer reads local browser-playable audio files from this folder.

Use these file names (one file for each channel):
  dhak.mp3
  kansar.mp3
  bell.mp3
  chanting.mp3
  fireworks.mp3
  crowd.mp3

Supported extensions:
  .mp3  .wav  .ogg  .m4a  .aac

The files are intentionally not included in this project. Add only audio you are licensed to
publish, or audio that is clearly public-domain / CC0 / otherwise permitted for web use.

A missing file is shown as OFF in the mixer and does not stop the rest of the page from working.
Short, reasonably compressed files are recommended because the app loads local audio into the
browser when a channel is played.
